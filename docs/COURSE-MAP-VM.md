# Level Up · VM Literacy — course map

_Generated from `content/vm/` by `npm run map-doc`. Edit the JSON, not this file._

Mini courses for students enrolled in **VCE Vocational Major Literacy**, linked to the key knowledge (KK) and key skills (KS) of the study design’s eight outcomes. Same structure as the F–10 pathway: Induction → five zones (starters, Level 2, boss) → Capstones. Reading levels work the same way. Codes such as **U1 O1 KK3** mean Unit 1, Outcome 1, 3rd key knowledge point, in study-design order.

1 of 32 mini courses built.
