# Level Up · VPC Literacy — course map

_Generated from `content/vpc/` by `npm run map-doc`. Edit the JSON, not this file._

Mini courses for students enrolled in **VPC Literacy**, linked to the learning goals (LG) and applications (AP) of the seven modules in the Victorian Pathways Certificate Literacy Curriculum Design. The units are standalone and can be done in any order, so VPC is one pathway: The Workshop → 6 zones, one per module (starters, Level 2, boss) → Your Project (Unit 4's negotiated project). Every course is hands-on: it ends with a real-world **Do it** task. Codes such as **U1 M1 AP3** mean Unit 1, Module 1, 3rd application, in curriculum order.

Reading levels work the same way as F–10 and VM, but aim higher: ▲ Foundation reads at about Year 5, ■ Core reads at about Year 7, ● Extended reads at about Year 9.
